# Avatar art provenance

Aino and Mansikki are original SVG drawings made for this project (Junction 2026, Valio Aimo challenge), written by
hand in `Avatar.tsx`. No third-party art, fonts or assets are used. Licence: same as the repository.

The placeholder moos in `src/cow/MooPlayer.ts` are synthesized at runtime with the Web Audio API, so no audio files
or third-party sounds are included. Recorded ElevenLabs Sound Effects moos (PLAN M17.1) need team approval first,
because generating them spends credits; their PROVENANCE.json will live in `public/sfx/moo/`.
