# Avatar art provenance

Aino and Mansikki are original SVG drawings made for this project (Junction 2026, Valio Aimo challenge), written by
hand in `Avatar.tsx`. No third-party art, fonts or assets are used. Licence: same as the repository.

Mansikki's moos in `public/sfx/moo/` were generated with the ElevenLabs Sound Effects API (SFX v3) by
`scripts/gen_moos.py` on a paid plan, which includes a commercial licence. Prompts, model and date are in
`public/sfx/moo/PROVENANCE.json`. The Web Audio synthesis in `src/cow/MooPlayer.ts` is only a fallback while the
clips load.
